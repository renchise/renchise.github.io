Website Privacy Policy

This page covers the static GitHub Pages website itself. App-specific privacy details live inside each app folder.

This website does not require account sign-in and does not intentionally collect personal data through its pages.

What the site does

Simple informational pages with links to the two Android apps, their policies, and their release pages.

Data handling

  • Hosted as static pages on GitHub Pages.
  • No user account is required to read the pages.
  • No sensitive document content or user files are stored by the website.

Ad disclosure

When the app pages mention ads, they refer to Google Mobile Ads / AdMob placements shown inside the Android applications. The website pages themselves do not contain advertisements.
