Security Practices

How your data is protected in Renchise VouchLink.

⚠️ IMPORTANT DISCLAIMER
Renchise VouchLink is not affiliated with, endorsed by, authorized by, sponsored by, or operated by the Singapore Government, GovTech Singapore, CDC, the Climate Vouchers programme, RedeemSG, or any government agency or voucher issuer.
🔐 Local Storage & Private Processing
All VouchLink data is processed and stored locally on your device. Voucher links and information are not uploaded to or stored on Renchise servers. The developer does not have access to your locally stored data.

Encryption

All voucher data is encrypted using AES‑256 encryption before being stored locally on your device. The encryption key is derived from a passphrase using SHA‑256. Backup files are encrypted with the same industry‑standard encryption.

Technical implementation: AES in CBC mode with PKCS5 padding, using a static IV and a key derived from a SHA‑256 digest of the passphrase.

Local Storage Only

All information — voucher links, balances, expiry dates, and preferences — is stored exclusively in a local SQLite database (Room) on your device. There is no cloud synchronisation, no remote backup, and no data sharing.

Permissions

  • READ_SMS (optional) — only required for user-initiated Batch Import from SMS. It checks links matching the configured voucher prefix within the look-back period. You can revoke this permission at any time.
  • INTERNET — used to open official voucher websites and load AdMob advertisements.

No permission is used to access contacts, location, camera, or microphone.

Backup Security

Exported backup files are encrypted with the same AES‑256 encryption. They can only be imported back into the app. The developer does not have access to your backup data.

Private Voucher Links & Sharing

Individual voucher links are personal redemption links. Users should understand that sharing a link gives the recipient access and may allow them to redeem the voucher. VouchLink processes all sharing actions locally and does not transmit these links to developer servers.

Recommendations

  • Use device lock (PIN / pattern / biometric) to protect your device.
  • Keep your Android system up to date.
  • Only install apps from trusted sources (Google Play Store).
  • If you share your device, consider exporting a backup and clearing app data before handing it over.
  • Double‑check links before sharing them with others.
  • Delete saved items you no longer need.
