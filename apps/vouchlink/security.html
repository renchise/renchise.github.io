Renchise VouchLink security

Use this page to explain how the app handles local files, device authentication, and sensitive content in plain language.

Recommended wording

  • Files remain local unless the user exports or shares them.
  • Use device security or app lock where the app supports it.
  • Do not imply that validation guarantees official approval.
  • Warn before exporting, sharing, or opening sensitive images in another app.

Keep sensitive flows separate

For VaultStudio, keep ID vault, passport photo, and Studio wording separate so users understand when a feature is for identity documents and when it is for general photo editing.
