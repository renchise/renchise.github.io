Security page

Security notes for photos, ID scans, and sensitive local files in VaultStudio.

VaultStudio is intended to work with your device’s own security settings where available. If your phone supports fingerprint, PIN, pattern, password, or a similar trusted screen-lock mechanism, you can use it to protect access to the device and any stored files.

For scanned IDs and vault items, the safest approach is to keep the device locked when not in use, avoid unnecessary sharing, and delete files that you no longer need.

  • Use the device’s native security features.
  • Share sensitive images only with trusted recipients.
  • Keep backups private and controlled.
  • Review exports before sending them onward.
